
# ROBO iOS External V3

A Flutter starter project for Android and Windows.

## Build downloads

1. Open the repository on GitHub.
2. Select the Actions tab.
3. Open "Build Android APK and Windows EXE".
4. Select "Run workflow" to start a manual build.
5. Open the completed workflow run.
6. Download the artifacts:
   - ROBO-Android-APK
   - ROBO-Windows-EXE

The Android artifact contains a release APK.
The Windows artifact contains a ZIP with the release application files.

This repository currently contains a starter interface.
It does not yet include a production backend, login system,
license validation, reseller dashboard, or key management.
